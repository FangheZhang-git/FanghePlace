ScholarMatch Privacy Policy

Last Updated: March 2026

Information We Collect

ScholarMatch may collect the following information:

  • Email address
  • GPA
  • SAT / ACT scores
  • Academic interests
  • Demographic information (optional)

How We Use Information

Information is used to match users with relevant scholarships and improve the platform.

Data Security

Passwords are securely hashed and user data is protected using industry-standard practices.

Data Sharing

ScholarMatch does not sell user data.

Abuse Prevention

When security verification is enabled, login and signup use Cloudflare Turnstile to help prevent automated abuse. Verification involves Cloudflare processing technical browser and device information; our server also sends your IP address and verification token to Cloudflare. We do not send your password or student profile to this verification service. See Cloudflare's privacy policy.
